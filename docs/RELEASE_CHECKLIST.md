# Checklist técnico de release

Este checklist é para a futura release após a integração visual. Não autoriza publicação automática.

- [ ] Versão atualizada em `ProjectSettings/ProjectSettings.asset`.
- [ ] Repositório limpo e sem arquivos locais restritos.
- [ ] Build Windows x86_64 reproduzida a partir do commit escolhido.
- [ ] ZIP da build criado e testado.
- [ ] Controles, créditos e README revisados.
- [ ] Descrição e screenshots finais preparados.
- [ ] Página itch.io preparada, sem publicar nesta etapa.
- [ ] Download testado em máquina limpa.
- [ ] Playthrough completo e regressão executados.
- [ ] QA registrado e bugs classificados.
- [ ] Tag/release criada somente após aprovação.
- [ ] Procedimento de rollback registrado.

Baseline técnico atual: `cc327ed` (commit local da auditoria; push pendente do desbloqueio do gate de build).
